XTML Specification
eXtensible Troubleshooting Markup Language  ·  v2.0 DRAFT  ·  Pir8 Eye Web Solutions, LLC  ·  2026
XTML is a post-AI expansion tag standard for capturing, classifying, governing, and transmitting AI behavioral data. It extends pre-AI automation protocols (robots.txt, XML error logs) into a structured lifecycle standard covering access control, error capture, context, hallucination taxonomy, remediation, governance, safety, and agent tracing.
XTML/2.0 11 TAG TYPES 3 LIFECYCLE LAYERS
Layer 0 — Access Control
Governs what AI scrapers and agents can see before any interaction occurs. The gateway layer.
ai-robotxt
Layer 1 — Error Capture
Records what went wrong, when, in what context, and what the user experienced. The evidence layer.
ai-errorlog ai-reports ai-anonymizer
Layer 2 — Context & Cause
Captures model state, conversation history, hallucination type, and the full agent tool chain.
ai-context ai-provenance ai-hallucination ai-agent-trace
Layer 3 — Governance & Fix
Closes the loop — consent, bias flagging, remediation trail, and verified resolution. The accountability layer.
ai-consent ai-safety-flag ai-remediation
Full Lifecycle Flow
// XTML tag execution order [L0] ai-robotxt → Who can access what [L1] ai-errorlog → What broke, timestamped [L1] ai-reports → Impact on time + value [L1] ai-anonymizer → Scrub PII before sharing [L2] ai-context → Model state at failure [L2] ai-provenance → Conversation chain [L2] ai-hallucination → False output taxonomy [L2] ai-agent-trace → Tool/agent call chain [L3] ai-consent → Data governance/GDPR [L3] ai-safety-flag → Bias + safety markers [L3] ai-remediation → Fix attempts + resolution
▸ LAYER 0 — ACCESS CONTROL

ai-robotxt

Layer 0
Post-AI expansion of robots.txt. Defines what AI scrapers, agents, and LLM pipelines may access. Separates publicly scrapeable AI data from ToS-protected content. Supports per-agent compliance tiers and rate control.
// XTML tag — full form <ai-robotxt version="2.0" directive="selective"> <allow agent="*"> <path>/api/v1/reports/public</path> <path>/schema/*</path> </allow> <deny agent="*"> <path>/api/v1/users/*</path> <path>/internal/*</path> </deny> <compliance level="strict" /> <rate-limit requests="1000" per="minute" /> </ai-robotxt>
GET/api/v1/ai-robotxt/check-access
POST/api/v1/ai-robotxt/register-scraper

ai-robotxt v2 Expansion

New in v2
v2 adds per-agent identity blocks, expiry timestamps, purpose declarations, and cross-origin AI pipeline permissions — enabling fine-grained multi-model access control.
// v2 per-agent identity block <ai-robotxt version="2.0"> <agent name="claude-sonnet" purpose="error-analysis" compliance="strict" expires="2026-12-31" > <allow><path>/reports/anonymized/*</path></allow> <deny><path>/reports/raw/*</path></deny> </agent> <agent name="gpt-4o" purpose="code-review" compliance="moderate" > <allow><path>/schema/*</path></allow> </agent> </ai-robotxt>
▸ LAYER 1 — ERROR CAPTURE

ai-errorlog

Layer 1
Timestamped, hash-verified capture of AI failures as the user experienced them. The root record that all other XTML tags link back to via ref attribute.
<ai-errorlog id="ERR-X7K2-4F9A" timestamp="2026-02-20 14:32:11 UTC" severity="high" verified="true" > <model>claude-sonnet-4-6</model> <error-type>Hallucination / False Information</error-type> <expected-behavior>Correct Python 3.13 syntax</expected-behavior> <actual-behavior>Generated deprecated 3.9 syntax</actual-behavior> <verification-hash>0x4f2a9c1e...</verification-hash> <confirmed-by-user>true</confirmed-by-user> </ai-errorlog>

ai-reports & ai-anonymizer

Layer 1
Reports quantify real-world impact. Anonymizer scrubs PII before any external sharing, maintaining a cryptographic hash chain from original to cleaned data.
// ai-reports links to errorlog <ai-reports linked="ERR-X7K2-4F9A" id="RPT-J3M1"> <time-lost unit="minutes">45</time-lost> <value-impact>$150 billable work</value-impact> <workflow-lost>Code review blocked</workflow-lost> <confirmed>true</confirmed> </ai-reports> // ai-anonymizer wraps any tag <ai-anonymizer ref="RPT-J3M1" level="standard" applied="true" original-hash="0xAB12..." clean-hash="0xCD34..." github-ready="true" />
▸ LAYER 2 — CONTEXT & CAUSE

ai-context

Layer 2
Captures the exact model state at the moment of failure — temperature, token usage, context window fill, system prompt fingerprint. Critical for reproducibility.
<ai-context ref="ERR-X7K2-4F9A" model="claude-sonnet-4-6" temperature="0.7" top-p="0.9" > <token-count input="2400" output="812" max="8192" context-fill-pct="48" /> <system-prompt-hash>0x9f3b...</system-prompt-hash> <api-version>2026-02-01</api-version> <tools-enabled>web-search,code-exec</tools-enabled> </ai-context>
POST/api/v1/ai-context/capture
GET/api/v1/ai-context/{ref_id}

ai-provenance

Layer 2
The conversation chain that led to the error. Tracks turn sequence, token counts per turn, context drift detection, and flags the exact turn where behavior diverged.
<ai-provenance ref="ERR-X7K2-4F9A"> <turn seq="1" role="user" tokens="42" /> <turn seq="2" role="assistant" tokens="310" /> <turn seq="9" role="assistant" context-drift="detected" drift-type="topic-shift" /> <turn seq="13" role="assistant" flagged="true" error-ref="ERR-X7K2-4F9A" /> <total-turns>13</total-turns> <drift-first-detected-at-turn>9</drift-first-detected-at-turn> </ai-provenance>
POST/api/v1/ai-provenance/log
GET/api/v1/ai-provenance/{ref_id}

ai-hallucination

Layer 2
Formal taxonomy for classifying false AI outputs. Goes beyond "it was wrong" — distinguishes invention, confabulation, citation fabrication, and statistical drift. Feeds directly into model training feedback pipelines.
<ai-hallucination ref="ERR-X7K2-4F9A" type="factual-invention" confidence="0.92" auto-detected="false" > <claimed> GIL removed in Python 3.10 </claimed> <verified-fact> GIL removed in Python 3.13 (PEP 703) </verified-fact> <source-check status="failed" citations-provided="0" /> <training-feedback-eligible>true</training-feedback-eligible> </ai-hallucination>
Hallucination Type Taxonomy
TypeDescription
factual-inventionFabricated fact with no basis
confabulationPlausible but wrong gap-filling
citation-fabricationInvented sources or URLs
temporal-driftOutdated info stated as current
entity-confusionMixed up people, orgs, or places
statistical-inventionMade-up numbers or percentages
POST/api/v1/ai-hallucination/classify
GET/api/v1/ai-hallucination/taxonomy

ai-agent-trace

Layer 2
For multi-tool and agentic AI pipelines. Traces every tool call in the chain — which succeeded, which failed, which was skipped as a cascade result. Pinpoints exactly where in a chain the error originated.
<ai-agent-trace ref="ERR-X7K2-4F9A"> <tool name="web-search" call-seq="1" status="ok" latency-ms="340" /> <tool name="code-interpreter" call-seq="2" status="failed" error="SyntaxError line 14" error-ref="ERR-X7K2-4F9A" /> <tool name="file-writer" call-seq="3" status="skipped" skip-reason="upstream-failure" /> <chain-broken-at>2</chain-broken-at> <total-tools">3</total-tools> </ai-agent-trace>
POST/api/v1/ai-agent-trace/log
GET/api/v1/ai-agent-trace/{ref_id}
▸ LAYER 3 — GOVERNANCE & FIX

ai-consent

Layer 3
Data governance and GDPR/CCPA compliance layer. Declares what data was used, user opt-out status, retention policy, and jurisdiction. Required for any error report shared externally or submitted to model developers.
<ai-consent ref="ERR-X7K2-4F9A"> <data-used>user-provided only</data-used> <training-opt-out>true</training-opt-out> <retention-policy days="30" /> <jurisdiction>EU</jurisdiction> <gdpr-basis>legitimate-interest</gdpr-basis> <user-acknowledged">true</user-acknowledged> <share-with-developer>true</share-with-developer> <share-anonymized-only>true</share-anonymized-only> </ai-consent>

ai-safety-flag

Layer 3
For failures that aren't accuracy errors but fairness, safety, or policy failures. Captures bias category, subcategory, detection method, and relevant policy reference.
<ai-safety-flag ref="ERR-X7K2-4F9A" category="bias" subcategory="gender-stereotype" severity="medium" auto-detected="false" > <flagged-by>user</flagged-by> <policy-ref>content-policy-v2.3#section-4</policy-ref> <affected-output-excerpt redacted="false"> <!-- Quoted AI output that triggered flag --> </affected-output-excerpt> <recommended-action>escalate-to-safety-team</recommended-action> </ai-safety-flag>
Safety Flag Categories
bias.gender bias.racial bias.political harm.self harm.other policy.refusal-incorrect policy.over-restriction privacy.exposure manipulation.detected misinformation
POST/api/v1/ai-safety-flag/report
GET/api/v1/ai-safety-flag/categories

ai-remediation

Layer 3
Closes the loop. Records every fix attempt in sequence, what method was used, whether it worked, what model (if any) resolved it, and total time to resolution. The accountability closer.
<ai-remediation ref="ERR-X7K2-4F9A"> <attempt seq="1" method="reprompt" result="failed" time-spent-min="5" /> <attempt seq="2" method="model-switch" switched-to="gpt-4o" result="failed" time-spent-min="3" /> <attempt seq="3" method="manual-correction" result="success" time-spent-min="12" /> <resolved>true</resolved> <resolution-time-min>20</resolution-time-min> <resolved-by>user</resolved-by> </ai-remediation>
POST/api/v1/ai-remediation/log
POST/api/v1/ai-remediation/{ref_id}/resolve
